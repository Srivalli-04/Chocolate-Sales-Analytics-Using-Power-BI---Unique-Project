# 🍫 Chocolate Sales Analytics Using Power BI

## 📌 Project Overview

The **Chocolate Sales Analytics** project is an interactive Power BI dashboard designed to analyze chocolate sales, profitability, product performance, regional sales, and salesperson performance.

The project transforms sales transaction data into meaningful business insights using interactive visualizations, KPI cards, and filters.

The objective is to understand sales patterns, identify high-performing products and regions, evaluate profitability, and support data-driven business decisions.

---

## 🎯 Business Problem

Chocolate businesses need to understand how their products perform across different regions, sales channels, and time periods. Without proper analysis, identifying profitable products, tracking sales trends, and evaluating salesperson performance can be challenging.

This project uses Power BI to analyze sales and profit data, helping stakeholders explore business performance and identify opportunities for improvement.

---

## 🎯 Project Objectives

* Analyze total sales and overall profitability.
* Identify top-performing chocolate products.
* Compare sales performance across countries and regions.
* Evaluate salesperson performance.
* Analyze sales trends over time.
* Examine sales channels and product categories.
* Explore discounts and their relationship with sales and profit.
* Build interactive dashboards for business performance monitoring.

## 📂 Dataset Description

The dataset contains chocolate sales and shipment information.

| Column Name      | Description                                       |
| ---------------- | ------------------------------------------------- |
| Shipment ID      | Identifier for a shipment record                  |
| Date             | Date associated with the shipment or sales record |
| Country          | Country associated with the transaction           |
| Region           | Geographic sales region                           |
| Product          | Name of the chocolate product                     |
| Product Category | Category of the product                           |
| Salesperson      | Person responsible for the sale                   |
| Sales Channel    | Channel through which the product was sold        |
| Boxes Shipped    | Number of boxes shipped                           |
| Unit Price       | Price per unit                                    |
| Discount %       | Discount percentage                               |
| Sales            | Recorded sales amount                             |
| Cost             | Cost associated with the sales record             |
| Profit           | Recorded profit amount                            |

*Column descriptions are based on the dataset structure used in this project.*
